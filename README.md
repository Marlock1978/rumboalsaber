# rumboalsaber.app

Web de presentación de **Rumbo al Saber** (versión nacional, en castellano con versión bilingüe). Archivo único generado desde `NACIONAL - Rumbo al Saber/web/` con `scripts/build_single_rumbo.py`.

El canal de actualizaciones de la app NO está aquí: sigue en `Marlock1978/rumbalsaber-web` (`app/version.json`), para no romper las apps instaladas.
