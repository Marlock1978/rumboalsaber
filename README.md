# rumboalsaber.app

Web de presentación de **Rumbo al Saber** (versión nacional, en castellano con versión bilingüe). Generada desde `NACIONAL - Rumbo al Saber/web/` con `scripts/build_site.py`: `index.html`, `privacidad.html` e `img/` (carga diferida).

El canal de actualizaciones de la app NO está aquí: sigue en `Marlock1978/rumbalsaber-web` (`app/version.json`), para no romper las apps instaladas.
